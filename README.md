## “便宜”是从哪省出来的

理解低价 VPS 的成本结构，比记住任何一张配置表都有用。价格压到 $3 一档时，商家只能从这几个地方省，每一个对应你会踩到的一种坑。

**超售。** 同一台物理机上多塞几台虚拟机，空闲时段完全看不出来，晚上八点到十一点一起跑就露馅：CPU 有 steal time、磁盘 IO 抖动、SSH 都变卡。配置表看不出超售，唯一办法是拿到机器后自己压测（步骤在后面）。便宜的机器不一定超售，但密度是低价的主要来源之一。

**上一代硬件。** 老 CPU 和大批量采购的 SSD 能把单机成本摊薄。这一项上 Evoxt 走的是相反路线，主打的就是高频单核，标称最高 6.0 GHz。有第三方测评机构在 2026 年 2 月测试过 VM-1，单核成绩与标称档位基本相符，这在小商家里不算常见。

**功能裁剪。** 快照、自动备份、额外 IPv4、DDoS 高防，很多商家把这些拆出来单独收费，配置表上看不见。Evoxt 的做法是把每周异地备份做成全系标配，额外 IP 明码 $3/月，加购项都写在价格页上。这里省不了钱，但至少你知道自己在为什么付钱。

**年付现金流。** 年付价常比月付便宜三到五成，代价是你提前把钱给了一个可能明年就不做的商家，中途搬家也不退。Evoxt 用月付标价，没有靠超低年付套餐锁你的钱，反过来你也没拿到那份折扣。

## 拿到机器后的 30 分钟验货流程

新机器开机后别急着装东西，先花半小时把这六件事做完，能省掉后面几个月的扯皮。

1. **连通性**：从你目标用户的网络做 `ping`、`mtr`、`traceroute`，重点看晚高峰（20:00–23:00）的丢包和抖动。白天数据好看不算数，晚上才是真实水平。
2. **磁盘 IO**：用 `fio`、`dd`、`ioping` 压一轮，看的是持续性而不是峰值。顺序写入长期低于 50MB/s、4K 随机低于 5k IOPS，日常操作就会有明显卡顿。
3. **CPU 稳定性**：`stress-ng` 连跑 10–30 分钟，观察频率是否掉下来、有没有温度节流迹象。短时间跑分高、长时间跑就掉频的机器，不适合干重活。
4. **带宽**：`iperf3` 加实际文件上下行，和商家标称的带宽对比。共享口跑不满是正常的，差太远就值得问一句。
5. **端口**：检查你要用的端口有没有被封，尤其是非标准端口。
6. **安全最小集**：改掉默认 SSH 端口、禁用密码登录只留密钥、开防火墙、装 Fail2ban，然后立刻配一个异地自动备份。

判断这台机器及不及格，有几个可对照的数值：1GB 内存是跑 Web 服务、反向代理和轻量容器的下限，2GB 更稳；磁盘顺序写入 50–200MB/s、4K 随机 5–20k IOPS 属于常见区间，低于这个范围容易感觉到卡；入门配置一般是 1 vCPU、512MB–2GB 内存、10–40GB 存储、1–3TB 月流量、100–1000Mbps 共享口。

## 哪些人不该买这个价位的机器

有几类业务，用 $3–6 的 VPS 是在给自己制造事故：金融支付类核心业务、要求 SLA 99.99% 以上的系统、重 IO 的数据库、实时音视频、需要通过 ISO 27001 或 SOC 2 审计的项目、持续满核计算的任务，以及经常被 DDoS 的业务。这些场景要的不是省钱，是有人对可用性负责。

还有一类容易忽略的区别：自己运维和商家代管是两种产品。InMotion 的同配置方案，4 vCPU / 8GB 自管 $13.99/月，托管 $43.49/月，差价买的是别人替你打补丁、做安全更新、出问题先排查。如果你不打算自己维护系统，那 $3 的机器再便宜也不适合你，省下来的钱会以别的方式还回去。
